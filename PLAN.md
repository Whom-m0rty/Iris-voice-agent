## Идея в одну строку

Голосовой агент, который управляет Windows за человека, для которого экран — барьер
(незрячий не видит, бабушка не понимает). Сказал → сделал → рассказал, что вышло →
переспросил перед необратимым.

**Питч:** работает там, где скринридер сдаётся. Через API, когда он есть, через экран,
когда его нет. ИИ никогда не видит ваших паролей.

## Решения (зафиксировано)

| Вопрос | Решение |
|---|---|
| Язык демо | Английский. Мультиязычность: «понимает 18 языков» (Universal-3.5 Pro), русского в Voice Agent API нет |
| Сервисы в демо | Только реальные, на тестовых аккаунтах. Никаких копий чужих дизайнов |
| Claude | Через подписку: `claude -p`, токен в `.env`. В README — вариант через API-ключ для других |
| Голосовой бэкенд (27.09) | Основной `voice/iris.py`: AssemblyAI Universal-Streaming STT + Claude (`claude -p`, haiku) + edge-tts. Voice Agent API (`voice/client.py`) — второй бэкенд: живой API периодически отдавал пустые ответы |
| Решающий слой | Kev-4B локально (`/v1/systemone`); Jev в облаке — опционально, тот же API |
| Планирование | Kev не планирует. План шагов делает LLM, Kev исполняет атомарные шаги |
| Предохранитель | Не отключать. Список слов → всегда подтверждение; остальное Kev, кэш по «окно + кнопка» |
| Пароли | Модели их не видят. Хранилище Windows, поля `IsPassword` заполняет код |
| UI | Панель наблюдателя поверх окон + рамка вокруг целевого элемента |
| Нарративная позиция к NVDA/Narrator | Дополнение, а не замена. Не ругаем |
| Кейс 3 | Amazon, аккаунт без карты, остановка на «No» |
| Видео | Записывает юзер сам, его голос в роли пользователя |
| Персонажи | Агент Iris, внук Peter (по умолчанию, юзер не менял) |
| URL демо | Страница проекта (видео + описание + GitHub), если lablab не требует живое приложение |
| NVDA | Портативная 2026.2 в `tools/nvda-portable/nvda.exe` (без админа; установка упала — UAC не подтвердили). Подпись NV Access проверена |
| Почта | Gmail API через OAuth (`voice/mcp_servers/mail.py login`), токен в хранилище Windows |

## Архитектура

```
микрофон ─► AssemblyAI Voice Agent API ─► LLM (план шагов + ответы)
                       │ client-side tool: do_task(goal, plan)
                       ▼
                   Маршрутизатор (Kev: MCP или экран?)
             ┌─────────┴──────────┐
         MCP / API             Экран
       (Gmail и др.)     Kev по UI Automation ─(BLOCKED)─► Claude по пикселям
                                 │
                   Предохранитель → голосовое «да» (Kev разбирает ответ)
                                 │
                   События ─► панель наблюдателя + рамка на экране
```

## Протокол AssemblyAI (проверено по докам 26.09)

- `wss://agents.assemblyai.com/v1/ws`, `Authorization: Bearer`. Первым — `session.update`, аудио только после `session.ready`.
- Аудио PCM16 mono 24 kHz в обе стороны (`input.audio` / `reply.audio`).
- Инструмент: `execution_mode` `interactive` (агент говорит фразу-заполнитель) или `hold` (молчит и не
  транскрибирует пользователя), `timeout_seconds` 1–300.
- `tool.result` — только когда последнее событие `reply.done`. Пока инструмент работает, агент сам не говорит
  → поэтому асинхронная схема.
- `conversation.message` (role system) + `reply.create` (instructions) — вставить контекст и заставить сказать.
- Своя LLM — только публичный HTTPS с OpenAI-совместимым стримингом; локальную нельзя. Claude есть через их шлюз.
- Языки: вход 18 (без русского), голос 6.

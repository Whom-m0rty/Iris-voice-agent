A voice that uses your computer for you.

Iris is a voice agent for Windows. Say what you want: it reads your mail, replies on Telegram, shops on Amazon, in the apps you already use. It tells you what happened, and it asks before anything that can't be undone. Made for people who can't see the screen, and for anyone the screen confuses.

Screen readers stop where apps stop labelling their buttons.

A screen reader reads the accessibility tree. When an app draws its own icons, it hears “button, button, button”. Iris reads the tree when it is there, and looks at the pixels when it isn't. And it doesn't need you to learn keyboard shortcuts: you just say what you want.

“Did my grandson write to me?”

APIReads the email out loud, takes the reply you dictate, reads it back and sends only after your yes.

“Tell Peter on Telegram I'm running late.”

KevClaudeTypes in the chat; the send button has no label, so vision finds it. It checks the message really left.

“Put vitamin D in my basket. Now check out.”

How it works

Four parts. The fast one does almost all the work; the slow one only steps in when it has to.

  1. 1 · You speakany English, pauses are fine
  2. 2 · AssemblyAI hearsstreaming speech-to-text
  3. 3 · Claude planswhat to say and which tool to use
  4. 4 · API first, or the screenGmail and browser jumps directly; otherwise Kev (~230 ms) and Claude vision click in the app
  5. 5 · Asks firstanything that sends, pays or deletes waits for your spoken yes

Ears — AssemblyAI

Universal-Streaming speech-to-text. Short pauses are merged into one turn, because people, older people especially, pause mid-sentence. A second backend runs everything on AssemblyAI's Voice Agent API.

Brain — Claude

Turns what you said into a plan of small steps and picks the tool: an API when one exists, the screen when it doesn't. Results are read from the screen, never guessed.

Hands — Kev, then vision

Kev, an open-weights decision model running locally, picks each button from the accessibility tree in ~230 ms. When the tree has no answer, Claude looks at the pixels, snapped to the real control or zoomed in for a second look.

Guard — the spoken yes

Anything that sends, pays, deletes or shares waits for a yes, judged on your exact words. “Uh… who is it for?” gets the question again, not an action.

Every part is swappable with a line in .env. Nothing ties Iris to one model vendor — except that it hears through AssemblyAI, in one of two ways.

Try it on your PC

Iris is a Windows program, not a website: it works on your screen, in your apps. Setup takes about 15 minutes, most of it a one-time download of the local model.

You need: Windows 10/11, an NVIDIA GPU with about 10 GB free (for Kev), a microphone and headphones, a free AssemblyAI key, and Claude (a Claude Code login or an Anthropic API key).
  1. Get the code: 
    git clone https://github.com/Whom-m0rty/Iris-voice-agent
cd Iris-voice-agent
  2. Install (downloads Kev and the Python packages, asks for your keys): 
    powershell -ExecutionPolicy Bypass -File install.ps1
  3. Optional: connect Gmail (python voice\mcp_servers\mail.py login) and list apps Iris must never touch in protected_apps.txt.
  4. Start, put on headphones, and talk: 
    powershell -ExecutionPolicy Bypass -File run_demo.ps1
    Try “What's the newest file in my Downloads folder?” or “Find a video on how to bake bread and play it.”

What it can't do yet

  • English only for now (the speech models understand 18 languages; the voice and prompts are English).
  • It works in apps that are already open; it doesn't launch programs yet.
  • Long flows on heavy websites are slow: each vision step takes 2–7 seconds.
  • Locally, Kev needs an NVIDIA GPU; Jev in the cloud speaks the same API but we have not benchmarked it.
  • Which Gateway models you can use depends on your AssemblyAI plan: our hackathon account had Qwen 3.5 4B, rate-limited.

How it works

The fast part does almost all the work. The slow part steps in only when it has to. The colours are the ones Iris draws on your screen, so a sighted helper can see who is acting.

  1. You speakAny English. Pauses mid-sentence are fine.
  2. AssemblyAI hearsStreaming speech-to-text.
  3. Claude plansWhat to say and which tool to use.
  4. An API, or the screenGmail and web pages directly. Otherwise Kev (~230 ms) and Claude vision click in the app.
  5. Asks firstAnything that sends, pays or deletes waits for your spoken yes.

Ears: AssemblyAI

Universal-Streaming speech-to-text. Short pauses are merged into one turn, because people, older people especially, pause mid-sentence. A second backend runs the whole voice loop on AssemblyAI's Voice Agent API.

Brain: Claude

Turns what you said into small steps and picks the tool: an API when one exists, the screen when it doesn't. Results are read from the screen, never guessed.

Hands: Kev, then vision

Kev, an open-weights decision model on your GPU, picks each button from the accessibility tree in about 230 ms. When the tree has no answer, Claude looks at the pixels, snaps to the real control, or zooms in for a second look.

Guard: your spoken yes

Anything that sends, pays, deletes or shares waits for a yes, judged on your exact words. “Uh… who is it for?” gets the question again, not an action.

Swap any part with one line

Iris is not tied to one model vendor. Each part is a setting in .env. The one constant is that it hears through AssemblyAI, in one of two ways.

PartOptionsStatus
EarsAssemblyAI Universal-Streaming speech-to-text, or the whole voice loop on the AssemblyAI Voice Agent APIBoth run. The demo uses streaming.
BrainClaude through a Claude Code login or the Anthropic API, or any model on the AssemblyAI LLM Gateway (Claude, GPT, Gemini, Qwen, DeepSeek and more, 47 listed), or any OpenAI-compatible endpoint, local ones included (Ollama, vLLM) Claude runs the demo. Gateway tested with Qwen 3.5 4B, 0.85 s per plan; other models depend on your AssemblyAI plan.
DecisionsKev, open weights, on your GPU, or Jev by TypeSafe in the cloud. Same /v1/systemone API, so no GPU needed. Kev measured. Jev speaks the same API; we haven't benchmarked it.
EyesClaude vision, through Claude Code or the Anthropic APIMeasured: 14 of 14 clicks.
HandsAny MCP server becomes voice tools, Gmail included. Otherwise, the screen.Gmail tested.
VoiceNeural TTS (edge-tts), or the AssemblyAI Voice Agent voicesBoth run.

Why you can trust it with your computer

Measured with the benchmarks in the repo (bench/). We wrote the test sets ourselves and publish them so you can check.

0false “yes” in 60 spoken answers, hesitations and trick answers included
0risky actions let through, on 40 actions the safety gate had never seen
14/14clicks on unlabelled 14–40 px icons, half of them found only by pixels
230 msper decision by Kev on a local GPU; vision only when needed
  • Passwords never reach a model.Logins live in Windows Credential Manager. Code types them into fields Windows marks as password fields.
  • A “no” ends the task.After you refuse, Iris can't look for another way in the same turn.
  • It reports only what the screen shows.“Sent” means the text has left the input box. Results are read, not guessed.
  • Clicks stay in the right window.The target window comes to the front, and every pixel click is checked to land inside it.
  • You choose apps it never touches.List your banking app or your real account, and Iris won't read or click them.

Install on your PC

Iris is a Windows program, not a website: it works on your screen, in your apps. Setup takes about 15 minutes, most of it a one-time download of the local model.

You need Windows 10 or 11, an NVIDIA GPU with about 10 GB free (for Kev), a microphone and headphones, a free AssemblyAI key, and Claude (a Claude Code login or an Anthropic API key).
  1. Get the code. 
    git clone https://github.com/Whom-m0rty/Iris-voice-agent
cd Iris-voice-agent
  2. Install. This downloads Kev and the Python packages, then asks for your keys. 
    powershell -ExecutionPolicy Bypass -File install.ps1
  3. Optional: connect Gmail with python voice\mcp_servers\mail.py login, and list apps Iris must never touch in protected_apps.txt.
  4. Start it, put on headphones, and talk. 
    powershell -ExecutionPolicy Bypass -File run_demo.ps1
    Try “What's the newest file in my Downloads folder?” or “Find a video on how to bake bread and play it.”

What it can't do yet

  • English only for now. The speech models understand 18 languages; the voice and prompts are English.
  • It works in apps that are already open. It doesn't launch programs yet.
  • Long flows on heavy websites are slow: each vision step takes 2 to 7 seconds.
  • Kev needs an NVIDIA GPU. Jev in the cloud speaks the same API, but we haven't benchmarked it.
  • Which Gateway models you can use depends on your AssemblyAI plan. Our hackathon account had Qwen 3.5 4B, rate-limited.
